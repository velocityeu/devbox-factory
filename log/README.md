# DevBox Factory - Log Files

This folder contains log files generated by DevBox Factory operations.

## Log File Naming Convention

- `devbox-YYYYMMDD-HHMMSS.log` - Main DevBox operations log
- `template-YYYYMMDD-HHMMSS.log` - Template creation logs
- `vm-YYYYMMDD-HHMMSS.log` - VM creation logs
- `install-YYYYMMDD-HHMMSS.log` - Tool installation logs
- `health-YYYYMMDD-HHMMSS.log` - Health check logs

## Log Retention

Log files are retained indefinitely by default. To clean up old logs:

```powershell
# Remove logs older than 30 days
Get-ChildItem .\log\*.log | Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-30) } | Remove-Item

# Or use devbox cleanup
.\devbox cleanup -Logs
```

## Log Format

Each log entry follows this format:
```
YYYY-MM-DD HH:MM:SS [LEVEL] Message
```

Levels: INFO, OK, WARN, ERROR

## Git Ignored

Log files (*.log) are excluded from version control via .gitignore.
